# Pokemon Run

Roblox-style 3D world prototype built with Three.js, TypeScript, and Vite.

## Run

```powershell
npm install
npm run dev
```

Open:

```text
http://localhost:5173
```

## Build

```powershell
npm run build
```

## Controls

- WASD: move
- Space: jump
- Shift: sprint
- Drag mouse: rotate camera
- Mouse wheel: zoom
